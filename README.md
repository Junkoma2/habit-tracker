# 習慣トラッカー

自分が毎日使いやすいことを第一に作った、シンプルな習慣記録 Web アプリです。

**→ https://junkoma2.github.io/habit-tracker/**

## なぜ作ったか

習慣管理アプリは「続けるモチベーション」をゲームっぽく高める作りのものが多いですが、自分が求めていたのはそういうものではありませんでした。
静かに、負担なく、毎日チェックを入れられる道具が欲しかった。このアプリはその一点を大切にしています。

## 主な機能

- 習慣の追加・編集・削除・並び替え（ドラッグ操作）
- 今日・昨日の記録（長押しで切り替え）
- 習慣の一時終了と再開（過去の記録は保持）
- カレンダーで達成状況を確認・月ピッカーで月を選択
- 分析タブで連続日数・最長連続・累計達成・今月達成・直近30日達成率を表示
- pull-to-refresh で最新状態に更新
- テーマカラーの変更（6色プリセット）
- データのバックアップ・復元（設定 → データ管理、JSON形式）
- PWA対応（ホーム画面に追加して使える）

## 使い方

1. 「+」ボタンから習慣を追加する
2. 毎日、達成した習慣のボタンをタップする
3. 昨日分を記録したいときは習慣ボタンを長押しする
4. カレンダータブで過去の達成状況を確認する
5. しばらく続けない習慣は「終了」にしておくと一覧がすっきりする

## データとプライバシー

- データはこの端末のブラウザ（localStorage）にのみ保存されます
- 外部サーバーへの送信は一切ありません
- ブラウザの「サイトデータを消去」を行うとデータが消えます。**機種変更前・定期的なバックアップを推奨します**
- 共有端末で使用する場合、他の人に記録が見られる可能性があります
